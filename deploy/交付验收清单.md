# 知华 CRM 基础版交付验收清单

知华科技（上海如静知华信息科技有限公司） · [官网](https://www.zhuatech.cn/) · 商业授权、部署与系统集成咨询微信：`zhuatech` / `zhuatech2`。

本清单用于“移动销售客户跟进”场景的部署验收。系统包含客户、联系人、商机、跟进、任务、账号管理、客户交接、客户 CSV 迁移及最近 100 条核心操作记录；报价、合同、订单、回款、发票、企业身份平台和外部系统集成不在基础版内。

## 部署前

1. 确认书面商业授权、使用主体、部署环境和支持范围。记录实际用户数、销售角色、现有客户数据来源与迁移范围。
2. 在空白主机按 [README](../README.md) 所列版本准备 Docker 与 Compose。生产环境使用独立域名和 HTTPS 入口，仅允许受控网络访问数据库和管理接口；不要直接暴露示例 Compose 的本地 HTTP 端口。
3. 配置独立强密码和密钥，设置 `CRM_DEMO_ENABLED=false`；核对 `.env` 文件权限，不把真实凭据、客户 CSV 或备份提交到仓库。
4. 制定日志与监控、备份保留和异地副本、审计归档、账号离职交接及故障联系人。基础版页面仅展示最近 100 条操作记录，不能替代长期合规归档。

## 验收演练

1. 从空库启动，核对 Flyway V1—V3 迁移与服务健康状态；用管理员创建销售与经理账号，确认普通销售不能读取其他人的客户或管理账号。
2. 按[操作手册](../docs/操作手册.md)完成客户→联系人→商机→跟进→任务链路。刷新与重启后核对数据保留。
3. 管理员用虚构数据下载模板、导入和导出客户 CSV；上传含错误行的文件，确认整批不写入。核对导出文件在电子表格中的显示，并按企业规则安全保存。
4. 经理把测试客户转给另一销售，核对关联商机和任务同步转移、历史跟进仍在、新负责人可访问、旧负责人无法访问；在操作记录中核对人员、时间和原因。
5. 执行[备份与独立恢复](README.md#备份恢复与升级)步骤，在隔离实例核对客户、联系人、商机、跟进、任务、账号及操作记录。升级前另存镜像和备份，在隔离环境演练回退。
6. 使用目标域名从电脑和手机验证 HTTPS、登录、客户录入、下载和上传；检查监控告警是否能发现服务和数据库故障。

## 验收记录

交付时记录源码版本与提交号、镜像摘要、数据库迁移版本、部署地址、测试账号清理情况、备份恢复时间、演练结果、已知限制和双方确认的后续定制项。真实客户数据只保存在授权环境，不进入公开测试仓库或截图。
